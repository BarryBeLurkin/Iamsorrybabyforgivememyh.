# I'm Sorry, My Love ❤️

## Files
- `index.html` — the website
- `photo.jpg` — the photo used as the full-page background

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload **both** `index.html` and `photo.jpg` into the repository's main/root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub to provide the published website link.

The background image line is inside the CSS in `index.html`:
`url("photo.jpg") center 42% / cover fixed no-repeat;`
Keep `photo.jpg` in the same folder as `index.html`, or update that filename if you rename the image.
